# Pytest Python Testing — NEXUS-CRIME

## When to use
Activate when authoring or executing tests in `backend/tests/` or testing synthetic data recall.

## Test Directory Structure
```
backend/tests/
├── unit/            # Correlation logic, risk formula tests against hand-computed outputs
├── integration/     # Full pipeline against synthetic ground-truth dataset (scripts/generator.py)
└── api/             # Postman/Thunder Client equivalent API endpoint tests (FastAPI TestClient/httpx)
```

## Unit Test Principles
- Test `ai/correlation/colocation.py`, `ai/correlation/comovement.py`, and `ai/scoring/risk_score.py` as pure functions where possible.
- Use explicit, hand-calculated mock fixtures to verify exact mathematical formula outputs:
  `risk_score = 0.30*centrality + 0.25*min(coloc/5, 1.0) + 0.25*min(comove/5, 1.0) + 0.20*call_freq_norm`.
- Verify graceful degradation: when a signal is missing, assert proportional reweighting; when all signals are missing, ensure undefined/excluded (never 0).

## Integration & API Tests
- Use `pytest-asyncio` and `httpx.AsyncClient` with app dependency overrides.
- Integration tests must validate 100% recall of the planted network generated by `scripts/generator.py`.
- Assert strict HTTP error status codes (e.g. 422 for missing case reference, 400 for invalid schemas).
